About

MANTAX Reference Library

MANTAX is a privacy-focused facial recognition system designed for ethical use cases such as missing persons identification, documentation verification, and consented identity matching.

Ethical Use Only: This tool must only be used with explicit consent and for legitimate, legal purposes. All data is stored locally and never transmitted to external servers. Users are responsible for complying with privacy laws (GDPR, CCPA) and obtaining proper authorization before processing biometric data.

Scientific & Safety Information: MANTAX uses state-of-the-art neural networks (ArcFace, FaceNet) with confidence scoring. Match results include probability bands, not binary yes/no answers. Always verify matches with additional evidence. Human-in-the-loop review is mandatory for all critical decisions. False positives and false negatives are possible.
